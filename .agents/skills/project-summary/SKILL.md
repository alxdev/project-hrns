# Project summary

Use this workflow when the user asks for a high-level view of a project.

1. Inspect the project files with the available read-only tools.
2. Identify the main directories, entry points, configuration files, and test areas.
3. Separate observations from reasonable inferences.
4. Report the structure briefly and cite the paths that support each important claim.

Do not modify files. If a required read-only tool is unavailable, request it from the harness before continuing.
