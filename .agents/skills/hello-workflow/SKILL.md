# Hello workflow

Use this skill as a compact example of a repeatable workflow.

1. Restate the requested outcome in one sentence.
2. Perform the smallest set of actions needed to reach it.
3. Verify the result.
4. End with a short report containing the outcome and any remaining limitation.

Keep the workflow concise and do not claim verification that was not performed.
